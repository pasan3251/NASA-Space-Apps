# Journal fonts

Self-hosted from the Google Fonts repository, retrieved 13 November 2026.

- `journal-display.ttf`: DM Serif Display Regular, https://github.com/google/fonts/blob/main/ofl/dmserifdisplay/DMSerifDisplay-Regular.ttf
- `journal-sans.ttf`: DM Sans variable, https://github.com/google/fonts/blob/main/ofl/dmsans/DMSans%5Bopsz%2Cwght%5D.ttf
- License text is retained beside each font as `journal-display-OFL.txt` and `journal-sans-OFL.txt`.

Both are distributed under the SIL Open Font License 1.1. These are unmodified font files; only local filenames differ.
